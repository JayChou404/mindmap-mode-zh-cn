# Mindmap Mode 中文语言包

这是 **Mindmap Mode 1.0.10** 的简体中文界面本地化插件。

## 作用

- 汉化 Mindmap Mode 的命令、菜单、工具栏、设置页、快捷键说明、查找栏、内容块对话框和提示信息。
- 不改动 Mindmap Mode 的思维导图解析、编辑和写回逻辑。
- 不修改你的 Markdown 笔记内容。

## 安装

1. 先在 Obsidian 中安装并启用原版 **Mindmap Mode**。
2. 解压本压缩包。
3. 把整个 `mindmap-mode-zh-cn` 文件夹复制到你的仓库：

   `.obsidian/plugins/`

   最终应为：

   `.obsidian/plugins/mindmap-mode-zh-cn/manifest.json`
   `.obsidian/plugins/mindmap-mode-zh-cn/main.js`
   `.obsidian/plugins/mindmap-mode-zh-cn/styles.css`

4. 重启 Obsidian，或在「设置 → 第三方插件」里重新加载插件。
5. 启用 **Mindmap Mode 中文语言包**。

## 兼容性

- 目标版本：Mindmap Mode 1.0.10
- Obsidian 最低版本：1.5.7
- 原版插件后续更新如果修改了英文界面文案，少数新文案可能暂时保持英文。

## 卸载

在 Obsidian 中禁用并删除 **Mindmap Mode 中文语言包** 即可。原版 Mindmap Mode 和笔记数据不会被删除。
